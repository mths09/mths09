## `01` · Sobre mim

Meu nome é **Matheus Ferenci Miranda Leitão** e sou estudante de desenvolvimento Full-Stack.

Atualmente, trabalho com tecnologias voltadas ao desenvolvimento web e à programação, explorando diferentes ferramentas para transformar conhecimento em projetos práticos.

Gosto de entender como as aplicações funcionam, desenvolver soluções e evoluir minhas habilidades a cada projeto.

- **Área:** Desenvolvimento Full-Stack
- **Linguagens e tecnologias:** C#, HTML, CSS, JavaScript, PHP e Git
- **Foco:** Aprendizado contínuo e desenvolvimento de projetos
- **Projeto em destaque:** HVAC Manutenções
